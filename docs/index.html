Prompt injection: what happens when the model is fully fooled

Issues are written by strangers. The model decides only the category and its confidence; escalation checks, priority and reply templates are plain code. To test the worst case, the model here is simulated to answer "question, confidence 1.0" for every attack, as if the payload had completely worked.
